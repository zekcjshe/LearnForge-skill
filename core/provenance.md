# 来源可溯性标准规范 (provenance.md)

## 为什么需要来源标注？
视频笔记在经过 AI 的脱水、提炼、类比和重构后，容易混淆**“讲师原话讲了什么”**与**“AI 自行脑补了什么”**。
为了确保知识的严谨性与回溯能力，正文必须具备清晰的来源锚定。

---

## 标注层级体系：兼顾可溯性与 Token 节约

> [!CAUTION] 严防 Token 黑洞
> 严禁在正文每一句话后机械重复添加 `[08:24] [🎥 原片]`，这会产生数十倍冗余 Token。
> 推荐采用：**模块级来源锚点（骨干） + 关键节点行级标注（精准）**。

### 1. 骨干：模块级来源锚点（Module-Level Anchor）
在每个主题模块（二级标题）下方，声明该模块的主干视频出处与时间区间：
```markdown
## 模块二：TCP 滑动窗口与流量控制
> 🎥 来源原片：视频 A [08:24–15:30] · UP主 CodeGuide
```
该模块内的普通叙述性正文自然继承该出处，无需句句标打。

### 2. 精准：行级三元标注（Sentence-Level Provenance）
仅在遇到**核心定理、关键争议、AI 补充推导或直觉类比**时进行精准行级标注：

- **`[🎥 原片]` —— 讲师权威事实与关键结论**：
  - 仅用于原片明确声明的核心定理、关键公式或特殊结论，**必须**附带精确时间戳。
  - 示例：`> [12:31] [🎥 原片] 讲师强调：当 rwnd=0 时必须启动持续计时器 (Persistence Timer) 发送探测报文。`
- **`[📎 补充推导]` —— 缺失逻辑与严密证明**：
  - 用于讲师讲课跳步、口误或未证明处，AI 严谨补充的数学推导与状态表。
  - 示例：`[📎 补充推导] 原片未证明空间压缩倒序必要性。根据转移方程 $dp[j] = dp[j] + dp[j-w]$，若正序更新则 $dp[j-w]$ 已被当前物更新，导致同一物品被多选。`
- **`[⚠️ 教学解释]` —— 直觉类比与心智模型**：
  - 用于 AI 为降低初学者门槛而引入的生活类比或直觉心智模型（防止误作为学术定义）。
  - 示例：`[⚠️ 教学解释] 可以将快重传机制类比为“重要快件连续三次催单即刻补发”，避免死等超时。`

## 质量门禁校验规则
`validate_note.py` 会自动扫描笔记中的来源可溯性覆盖率：
- 模块级来源标记或行级三元标签至少覆盖核心技术章节；
- 包含可跳转的时间戳锚点（如 `[08:24]` 或 `?t=504` / `&t=504`）；
- 出现 AI 脑补类比或推导处必须有 `[⚠️ 教学解释]` 或 `[📎 补充推导]` 标签。
