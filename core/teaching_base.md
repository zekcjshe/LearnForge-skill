# 通用教学底层原则 (teaching_base.md)

本文件定义无论任何学科领域（算法、网络、密码学、操作系统、工程架构等）都必须无条件遵循的**底层认知教学铁律**。

---

## 核心认知教学五项铁律

### 1. 直觉先于抽象 (Intuition Precedes Abstraction)
- **绝对禁止**一上来抛大段数学形式化定义、RFC 术语或深奥术语。
- **强制规则**：每个概念必须以现实生活场景、具体数字小例子或痛点情境切入，先建立“为什么需要这个东西”的心理共鸣，再给出形式化定义。

### 2. 双重锚定心智模型 (Dual-Anchor Mental Model)
- **生活形象类比**：提供一个通俗形象的生活隐喻（如：滑动窗口像“传送带上的质检托盘”，慢开始像“汽车起步指数踩油门”）；
- **技术实体映照**：立刻紧跟该类比在计算机内部的真实物理存在（如：内存缓冲区指针对、TCP Header 中的 16 位 window 字段）。
- **防呆声明**：类比仅用于建立第一感性认知，必须明确声明类比的边界，防止初学者生搬硬套。

### 3. 极简可推演模型 → 演进阶梯 (Scaffolding Progression)
- **先立最小可用模型**：
  - 算法类：提供 ≤30 行、零炫技的朴素可运行版本；
  - 协议/理论类：提供极简状态机流动图或手工算术推演（带具体小数字）；
- **演进清单**：对比最小模型，逐项指出“为什么它不够好”以及“工业级/优化版改动了哪一步、带来了什么飞跃”。

### 4. 错误驱动与陷阱实验室 (Error-Driven Trap Lab ⚠️)
- 初学者最深刻的理解往往来自“撞墙”：
  - ❌ **经典错误/反例**：写出典型错误代码、错误配置或危险假设；
  - 🔥 **底层状态演变推演**：逐步推演底层内存、指针、报文队列或数学状态是如何一步步变坏、越界、溢出或死锁的；
  - ✅ **防御性法则/修正口诀**。

### 5. 闭环主动回忆 (Active Recall)
- 每个模块或全篇结尾必须设立**闭环自测**：
  - 题型包含：概念本质理解、边界反例识别、真实场景迁移应用；
  - 必须配套**原生折叠式参考答案 (`<details><summary>...</summary></details>`)**，供学习者自查自测。
