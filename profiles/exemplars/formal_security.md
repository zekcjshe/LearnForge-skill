# 认知范例：形式安全与数学证明 (formal_security.md)

## 适用特征
密码学算法 (RSA, ECC, AES)、数字签名、零知识证明 (ZKP)、哈希消息认证码 (HMAC)、安全通信协议等具有“严格威胁假设、数学难题基石、形式化安全定义”的主题。

---

## 教学组织骨架

### 1. 直觉痛点与威胁模型 (Threat Model)
- **现实场景切入**：例如“在公开大厅和朋友说悄悄话”、“证明支票是本人签署且未被修改”；
- **明确攻击者能力边界**：
  - 被动窃听者 (Eavesdropper) vs 主动中间人篡改 (MITM)；
  - 已知明文 (CPA) vs 选择密文攻击 (CCA)。

### 2. 形式化安全目标
- 解释该方案到底承诺了什么安全等级：
  - 完美保密性 (Shannon Perfect Secrecy)；
  - 语义安全 (IND-CPA / IND-CCA2)；
  - 抗碰撞性 (Collision Resistance) 与原像抗性。

### 3. 数学难题基石与手工小数字推演
- **底层难题展开**：大数分解、离散对数 (DLP)、椭圆曲线 (ECDLP) 或格难题 (LWE)；
- **小数字算术推演**：使用具体小质数（如 $p=61, q=53$）跑通密钥生成、加解密全闭环，绝不用抽象符号轰炸；
- **数学证明闭环**：利用欧拉定理推导解密还原的正确性。

### 4. 典型攻击向量与工程缺陷 ⚠️
- 填充 Oracle 攻击 (Padding Oracle)；
- 随机数重用风险（如 ECDSA 随机数 $k$ 重用导致私钥被直接反解）；
- 计时侧信道攻击 (Timing Attack) 与常数时间实现 (Constant-time) 必要性。
